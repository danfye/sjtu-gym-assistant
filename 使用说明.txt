交大健身房预约助手 · Windows 便携分享版

开始使用
1. 将压缩包完整解压到一个可写文件夹，例如 D:\GymBooker。
   不要在压缩包预览窗口里直接运行，也不要只复制启动文件。
2. 双击“启动预约助手.bat”。已附带 Python、依赖和 Tesseract OCR，无需另外安装。
3. 填写你自己的 jAccount 账号和密码，浏览器选择电脑上已安装的 Edge 或 Chrome。
4. 先点“仅登录”，再选择日期和时段，点“检测空位（不下单）”确认可以查询。
5. 确认时段后，按需要启动“健身房定点预约”“健身房回流抢占”或“扫描指定日期范围”。

运行条件
- 本包适用于 Windows 10/11 x64，电脑需要安装 Edge 或 Chrome。
- 登录、查询、预约和消息通知需要联网；首次运行可能需要下载浏览器驱动。
- 自动登录会识别验证码，识别失败时可以重试；网站改版也可能影响登录或预约。
- 运行扫描时保持电脑开机联网，关闭助手会停止它启动的任务，电脑休眠期间不能扫描。

预约和记录
- 首次打开不会自动开始预约。检测按钮不下单，预约和扫描按钮会实际尝试下单。
- 默认时段是 7-22，使用前请改成你愿意训练的时段，例如 19-21。
- 当前版本会在成功预约一小时后尝试紧接着的下一小时，下一小时可能超出输入时段。
  连续两小时能否成功以学校系统返回为准，请核对学校系统里的实际订单。
- 回流与范围扫描默认每 5 分钟一轮；“监控到”和“最多分钟”可以限制运行时间。
- 日历来自本地预约记录，不是学校订单的实时同步。手动切换状态不会创建或取消学校订单。
- 训练统计按今天及以前的 booked 日期计数，一天记一次，不等于到场签到次数。

通知
- 飞书：填写自己的群机器人 Webhook；启用签名校验时同时填写 Secret。
- 也可填写 Server酱 Key 或企业微信群机器人 Webhook；全部留空也能预约。
- 点击“测试通知”检查是否收到，保存设置后再启动任务。
- 已经运行的任务不会自动采用之后修改的通知配置，需要结束后重新启动任务。

个人数据
- 分享包内没有原使用者的账号、密码、Cookie、推送密钥、日志和预约历史。
- 默认不保存密码；勾选保存密码后会写入本地明文 ui_settings.json。
- 使用后，个人设置在 ui_settings.json；Cookie 和预约记录在 state；日志在 run.log 和 logs。
- 以后转发给别人，请转发最初收到的干净 ZIP，不要压缩已经使用过的文件夹。

遇到问题
- 启动失败：检查是否完整解压；如存在 startup-error.log，可查看该文件。
- 登录失败：确认账号密码、网络和所选浏览器，取消“无头模式”后观察登录过程。
- 日历显示已约但学校订单已取消：切换该日期的本地状态，再重新开始任务。
- 本包附带的库及其许可证保留在 runtime 目录。具体版本见 bundled-versions.json。
